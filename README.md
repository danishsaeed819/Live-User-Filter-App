# Live User Filter App

## Overview

Live User Filter App is a lightweight web application built with Vanilla JavaScript that allows users to search and filter a list of users in real time. The application updates results instantly as the user types, providing a smooth and responsive search experience.

## Features

- Real-time user search
- Instant filtering without page reload
- Pure JavaScript implementation
- Responsive and clean user interface
- Fast DOM updates for better performance

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## Key Concepts

- DOM Manipulation
- Event Handling
- Real-Time Search
- Array Filtering
- Performance Optimization
- Debounced Input Handling

## Project Purpose

This project demonstrates the implementation of real-time search and filtering functionality using pure JavaScript without relying on external libraries or frameworks. It highlights efficient DOM manipulation techniques and basic performance optimization practices.

## How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Type in the search box to filter users instantly.
